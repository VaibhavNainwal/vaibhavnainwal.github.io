# Vaibhav Nainwal academic website

A clean, independently implemented personal academic website inspired by common research-page conventions, including section overview cards, paper lists, and expandable abstracts. It is **not** a copy of any other website's protected source code or branded artwork.

## Publish using GitHub Pages
1. Create a **Public** repository named `VaibhavNainwal.github.io` under the `VaibhavNainwal` GitHub account (GitHub repository naming is not case-sensitive).
2. Upload **the contents of this folder** into the repository root, preserving `assets/`.
3. Open repository **Settings → Pages**, then select **Deploy from a branch**, **main**, **/(root)** and save.
4. Visit `https://vaibhavnainwal.github.io` once deployed.

## Add your photo (no coding needed)
- Name the photo `profile.jpg` (JPG format) and upload it inside `assets/`.
- The page automatically displays that image, replacing the initials placeholder. If you prefer PNG, change `assets/profile.jpg` to `assets/profile.png` in `script.js`.
- Portrait-oriented photos work best (about 800 × 1000 px).

## Edit content
- `index.html` contains the biography, research, policy and data entries.
- `styles.css` contains styling and layout.
- `script.js` controls the mobile menu and optional photograph.
- Replace `assets/Vaibhav_Nainwal_CV.pdf` to update the CV.
